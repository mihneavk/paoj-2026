# Platforma E-Ticketing

## 1. Actiuni / Interogari posibile in sistem
1. Adauga o locatie noua.
2. Inregistreaza un utilizator nou (Client sau Organizator).
3. Adauga un eveniment nou in sistem.
4. Listeaza toate evenimentele disponibile, sortate cronologic.
5. Cauta un eveniment specific folosind ID-ul.
6. Verifica numarul de locuri disponibile pentru un eveniment.
7. Cumpara un bilet pentru un client la un anumit eveniment.
8. Afiseaza istoricul biletelor achizitionate de un client.
9. Sterge un eveniment din sistem.
10. Afiseaza toti utilizatorii inregistrati.

## 2. Tipuri de obiecte din domeniu
`Utilizator`, `Client`, `Organizator`, `Locatie`, `Eveniment`, `Bilet`, `BiletId`, `Comanda`.
